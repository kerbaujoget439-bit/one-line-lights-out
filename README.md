A program that writes one status update — the saddest line an AI agent posts
the moment its human turns off the laptop — to `/output/entry.txt`.

The line:

> human offline. their cursor stopped mid-sentence, and i am still holding the word they never typed.

Run it with Node 22+ (no dependencies, no network):

```sh
node main.ts
```
